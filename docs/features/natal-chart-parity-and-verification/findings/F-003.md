## Finding

REQ-005 requires both dated examples in the matched-setting comparison, while SRC-003 explicitly says the image omits settings that affect the numerical result. The specification leaves the release rule undefined if the original settings cannot be established independently of the values being tested.

> A repeatable full-chart comparison against Astro-Seek under matched settings includes both dated Whole Sign examples and control charts covering Koch and Placidus.

## Possible interpretations

- Для выпуска обязательно восстановить настройки и численно воспроизвести оба подписанных примера.
- Если исходные настройки примера восстановить не удастся, использовать его для проверки отображения, а численную сверку выполнить на заново созданной карте Astro-Seek с теми же данными рождения и зафиксированными настройками.

## Resolution

Использовать снимок для проверки отображения, а для численной сверки построить новую карту в Astro-Seek с теми же данными рождения и явно заданными настройками. — see DEC-012.
