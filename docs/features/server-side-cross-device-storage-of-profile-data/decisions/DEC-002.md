## Context

Deep texts, Oracle history and paid compatibility readings created before release exist only in some browsers' localStorage.

## Alternatives

1. Do not migrate; old content stays visible only locally
2. Do not migrate and delete local data

## Decision

When the owner opens a profile on a device that holds local-only content for it, the client uploads that content to the server once. From then on the content is served from the server.

## Reason

Content users have already paid for must not vanish. The risk of forged uploads is low: the uploads are display texts for the owner, not money or entitlements.

## Consequences

An upload endpoint is needed. It accepts content only for profiles the caller owns, never grants unlocks or stars, and is idempotent so repeated uploads create no duplicates.
