## Statement

Each profile detail tab (chart, planets, aspects, houses, interpretation, oracle, transits, compatibility, astrologer, premium content) shall offer a help bubble explaining what the tab contains and what the user gets from it.

## Acceptance Criteria

- [x] Every tab label has a help bubble.
- [ ] Opening help on a tab does not switch the tab on touch devices; switching tabs still works with one tap.
