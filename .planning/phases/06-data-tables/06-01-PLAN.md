2. **Create `web/src/components/chart/PlanetsTable.tsx`:**

   Props:
   ```typescript
   interface PlanetsTableProps {
     points: ChartPoint[];
   }
   ```

   Render a table with columns:
   | Column | Content | Width |
   |--------|---------|-------|
   | Body | Planet glyph + name (e.g., "☉ Sun") | auto |
   | Sign | Zodiac glyph + sign name, colored by element (e.g., "♈ Aries" in fire red) | auto |
   | Degree | Formatted as `{deg}°{arcmin}'` (e.g., "15°23'") | auto |
   | House | House number or "—" if null | auto |

   Implementation details:
   - Import `Table, TableHeader, TableBody, TableRow, TableHead, TableCell` from `@/components/ui/table`
   - Import `PLANET_GLYPHS, ZODIAC_GLYPHS, SIGN_ELEMENTS, ELEMENT_COLORS` from chart constants
   - Import `useTranslation` from react-i18next
   - Column headers use i18n keys: `t("tables.planets.body")`, `t("tables.planets.sign")`, etc.
   - Format degree: `Math.floor(point.degreeInSign)` for degrees, `Math.round((point.degreeInSign % 1) * 60)` for arcminutes. Pad arcminutes to 2 digits.
   - Sign name colored with element color: `style={{ color: ELEMENT_COLORS[SIGN_ELEMENTS[point.sign]].text }}`
   - Sort order: keep the natural order from `points` array (Sun, Moon, Mercury... Pluto) — this is the standard astronomical order from the backend.
   - Table rows should have subtle hover effect: `className="hover:bg-muted/50"`

1. **Create `web/src/components/chart/AspectsTable.tsx`:**

   Props:
   ```typescript
   interface AspectsTableProps {
     aspects: ChartAspect[];
   }
   ```

   Render a table with columns:
   | Column | Content | Width |
   |--------|---------|-------|
   | Body A | Planet glyph + name (e.g., "☉ Sun") | auto |
   | Aspect | Aspect glyph + type name, colored by aspect type (e.g., "△ Trine" in blue) | auto |
   | Body B | Planet glyph + name (e.g., "☽ Moon") | auto |
   | Orb | Formatted as `{orb}°` to 1 decimal (e.g., "2.3°") | auto |
   | Exactness | Visual indicator: a small inline bar or percentage (e.g., "94%" from `Math.round(exactness * 100)`) | auto |

   Implementation details:
   - Import Table components from `@/components/ui/table`
   - Import `PLANET_GLYPHS, ASPECT_GLYPHS, ASPECT_COLORS` from chart constants
   - Import `useTranslation` from react-i18next
   - Column headers use i18n keys: `t("tables.aspects.bodyA")`, `t("tables.aspects.type")`, etc.
   - Aspect type name: reuse existing `t("chart.aspects.conjunction")` etc. from Phase 5 i18n
   - Aspect type + glyph colored: `style={{ color: ASPECT_COLORS[aspect.type] }}`
   - **Sort by exactness descending** (most exact aspects first) — strongest aspects are most important
   - Exactness indicator: render a small `<div>` bar with width proportional to exactness (e.g., `width: ${exactness * 100}%`), colored by aspect type. Or simply show the percentage.

   - Orb displayed to 1 decimal: `aspect.orb.toFixed(1)`
