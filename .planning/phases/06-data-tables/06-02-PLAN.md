   ```tsx
   {chartData && (
     <Tabs defaultValue="chart" className="w-full">
       <TabsList className="grid w-full grid-cols-4">

         <TabsTrigger value="aspects">{t("tabs.aspects")}</TabsTrigger>
         <TabsTrigger value="interpretation">{t("tabs.interpretation")}</TabsTrigger>

       <TabsContent value="chart">

       </TabsContent>

       <TabsContent value="planets">
         <Card>
           <CardContent className="pt-6">
             <PlanetsTable points={chartData.points} />
           </CardContent>
         </Card>
       </TabsContent>

       <TabsContent value="aspects">
         <Card>
           <CardContent className="pt-6">
             <AspectsTable aspects={chartData.aspects} />
           </CardContent>
         </Card>
       </TabsContent>

       <TabsContent value="interpretation">

           <CardContent className="py-6">

               {t("tabs.interpretationPlaceholder")}
             </p>
           </CardContent>
         </Card>
       </TabsContent>
     </Tabs>
   )}
   ```

   **Keep the existing behavior:** Chart loading state, chart error state, and the conditional render all remain. The tabs wrap the content that was previously just `<NatalChart chart={chartData} />`.

   **Handle chart loading/error outside tabs:** The loading spinner and error message should appear where the tabs would be (before chartData is available). Once chartData loads, the full tabbed UI appears.

   **Default tab:** "chart" — the chart wheel is the primary view.
