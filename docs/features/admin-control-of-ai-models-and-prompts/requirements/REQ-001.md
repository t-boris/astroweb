## Statement

The system shall show, in a new "AI" tab of the Admin page, every AI task the backend runs together with its effective model, whether it uses the code default or a saved override, its output limit and the price of its model.

## Acceptance Criteria

- [x] The Admin page has an "AI" tab next to Overview and Business; it is English like the rest of the Admin page
- [x] The tab lists all AI tasks: Oracle, Oracle in letters, Compatibility, Deeper interpretation, Forecast, Premium PDF sections, Letter analysis, Letter writing, News digest, Fact extraction
- [x] Each task shows a short description of where it is used, the provider, the model label and id, "default" or "custom", the output limit and the model's input/output price per million tokens
- [x] The list is built from the server's task registry, so a task added in code appears without UI changes
- [x] Before any override exists, every task shows exactly the model and limits it uses today
