<task type="auto">
  <name>Task 1: Scaffold Vite React-TS app with Tailwind v4 and shadcn/ui</name>
  <files>web/ (entire directory scaffold)</files>
  <action>
1. **Create Vite project:**
   - Run `npm create vite@latest web -- --template react-ts` from root
   - Run `npm install` from root to link workspace

2. **Initialize shadcn/ui** (handles Tailwind v4 setup automatically):
   - Run `cd web && npx shadcn@latest init` from web/ directory
   - When prompted: select style **"default"** (Vega/New York — whichever is the default classic style), base color **"neutral"** or **"slate"**, CSS variables **yes**
   - This automatically installs: tailwindcss v4, @tailwindcss/vite plugin, tw-animate-css, class-variance-authority, clsx, tailwind-merge, lucide-react
   - This creates: components.json, updates vite.config.ts with tailwindcss plugin, creates/updates src/index.css with Tailwind v4 `@import "tailwindcss"` and `@theme inline` block, creates src/lib/utils.ts with `cn()` helper

3. **Verify shadcn init results:**
   - web/src/index.css should have `@import "tailwindcss"` (NOT `@tailwind base/components/utilities` — that's v3)
   - web/vite.config.ts should have `@tailwindcss/vite` plugin
   - web/src/lib/utils.ts should export `cn()` function
   - web/components.json should exist with component config

4. **Configure vite.config.ts path alias** (if not already set by shadcn):
   - Ensure `resolve.alias` maps `"@"` to `path.resolve(__dirname, "./src")`
   - Ensure `@vitejs/plugin-react` is included
   - Ensure `@tailwindcss/vite` plugin is included

5. **Update web/tsconfig.json and web/tsconfig.app.json**:
   - Add path alias: `"paths": { "@/*": ["./src/*"] }` in compilerOptions
   - Ensure `"strict": true`

Do NOT install `tailwindcss-animate` — it's deprecated for Tailwind v4. shadcn/ui init installs `tw-animate-css` automatically.
Do NOT create tailwind.config.js — Tailwind v4 uses CSS-based configuration via `@theme inline` in index.css.
Do NOT install `react-router-dom` — that's handled in Plan 01-03.
  </action>
  <verify>
- `cd web && npm run dev` starts Vite dev server without errors
- `cd web && npm run build` succeeds
- `cat web/src/index.css` contains `@import "tailwindcss"` (v4 syntax)
- `cat web/components.json` exists (shadcn/ui configured)
- `cat web/src/lib/utils.ts` exports cn() function
  </verify>
  <done>Web app scaffolded with Vite + React 19 + TypeScript, Tailwind v4 CSS-based config, shadcn/ui initialized with cn() utility, path alias @ configured, dev server and build both work.</done>

<task type="auto">
  <name>Task 2: Configure Firebase client SDK and create App shell</name>
  <files>web/src/lib/firebase.ts, web/src/App.tsx, web/src/main.tsx, web/src/index.css</files>
  <action>
1. **Install Firebase client SDK:**
   - Run `cd web && npm install firebase`

2. **Create web/src/lib/firebase.ts** — Firebase client with emulator auto-connect:
   ```
   - Import initializeApp from "firebase/app"
   - Import getFirestore, connectFirestoreEmulator from "firebase/firestore"
   - Import getFunctions, connectFunctionsEmulator from "firebase/functions"
   - Create firebaseConfig object with projectId "astroweb-dev" (placeholder, matches .firebaserc)
   - Export const app = initializeApp(firebaseConfig)
   - Export const db = getFirestore(app)
   - Export const functions = getFunctions(app)
   - Auto-connect to emulators in dev mode:
     if (import.meta.env.DEV) {
       connectFirestoreEmulator(db, "127.0.0.1", 8080)
       connectFunctionsEmulator(functions, "127.0.0.1", 5001)
     }
   ```
   Use `import.meta.env.DEV` (Vite's built-in), NOT `process.env.NODE_ENV`.

3. **Update web/src/App.tsx** — Minimal app shell:
   - Import from shadcn/ui's Button component (install it first: `cd web && npx shadcn@latest add button`)
   - Create a centered layout with:
     - App title "AstroWeb"
     - A subtitle or description
     - A placeholder button
   - Use Tailwind utility classes for layout (flex, min-h-screen, items-center, etc.)
   - Keep it minimal — routing and real pages come in Plan 01-03

4. **Clean up default Vite files:**
   - Remove web/src/App.css (styles go in index.css via Tailwind)
   - Remove default Vite SVG assets and counter logic from App.tsx
   - Keep web/src/main.tsx clean: render App with StrictMode

5. **Verify web/src/main.tsx** imports:
   - Must import "./index.css" (Tailwind entry point)
   - Must import App and render with createRoot

Do NOT add routing here — that's Plan 01-03. Do NOT add i18n imports — that's Plan 01-03.
  </action>
  <verify>
- `cd web && npm run build` succeeds with no errors
- `cd web && npx tsc --noEmit` passes (no TypeScript errors)
- `cat web/src/lib/firebase.ts` shows emulator auto-connect with `import.meta.env.DEV`
- Button component renders (shadcn/ui working)
  </verify>
  <done>Firebase client SDK configured with emulator auto-connect for dev mode. App shell renders with Tailwind styling and a shadcn/ui Button component. No default Vite boilerplate remains. Build and type-check pass.</done>
