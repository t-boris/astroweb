## Summary

The user's original request, spoken in Russian. They want small help bubbles (popover / mouse-over / pop-up) on all definitions, tabs and "models", explaining what each element is and why it is there. The request is not limited to astrology definitions: they stress that the main point is for the UI itself to describe everything.

## Origin

intake

## Content

Я хочу, чтобы у всех, особенно определений, тэбов, моделей, были pop-over, mouse-over, pop-up, help, ну, такие облачка, которые появлялись и описывали, что это такое, почему это. Ну, в общем, все эти описания, чтобы человек понимал, что это, что и что. И не только в определениях, но в основном в самом UI, чтобы UI имела описание всего.
