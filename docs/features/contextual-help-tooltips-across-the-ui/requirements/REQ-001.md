## Statement

Every displayed astrological term — planets, zodiac signs, houses, aspect types, house systems, orb and exactness — shall offer a help bubble containing a short generic definition plus 1–2 sentences on why it matters / what it means for the user, with no glossary page or 'Learn more' link; the bubble shall use a popover-capable component that fits a short paragraph, and EN and RU content shall be written for every help key.

## Acceptance Criteria

- [ ] Each planet, sign, house and aspect type shown in the profile tables, chart controls and filters has a help bubble.
- [ ] The Houses tab shows the house system the chart uses (Koch, Placidus or Whole Sign) as a read-only label with a help bubble; help texts exist for all three systems (DEC-007).
- [ ] Orb and exactness column headers have help bubbles.
- [ ] Each help text contains a short definition followed by 1–2 sentences on why it matters / what it means for the user, at most ~3 sentences in total.
- [ ] No help bubble contains a 'Learn more' link or a link to a glossary page, and no glossary page exists.
- [ ] Help bubbles are rendered with a popover-capable component that displays a short paragraph in full without truncation.
- [ ] Every help text key has non-empty content in both the EN and RU translation files.
- [ ] Texts are identical for all users and contain no chart-specific or AI-generated content.
- [ ] Existing chart-planet tooltip data content is unchanged.
