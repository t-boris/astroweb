## Context

Content depth drives bilingual content volume and component type (tooltip vs popover).

## Alternatives

1. One-line definition only (~15 words)
2. Short definition plus 'Learn more' link to a glossary page

## Decision

Each help bubble contains a short definition plus 1–2 sentences on why it matters / what it means for the user; no glossary page or 'Learn more' link.

## Reason

The request explicitly asks for both 'what it is' and 'why'; avoids a new glossary page.

## Consequences

Bubbles need a popover-capable component that fits a short paragraph; EN and RU content is written for every key.
