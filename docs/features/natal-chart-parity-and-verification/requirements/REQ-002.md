## Statement

Calculate and display the additional natal points and motion indicators visible across the reference charts. Use the dated Astro-Seek examples to verify the calculation conventions for the lunar nodes, Black Moon Lilith and Part of Fortune, adopting a convention for each point only when the numerical reproduction unambiguously confirms it. If the original settings for a dated Whole Sign example cannot be independently confirmed, use its screenshot for display verification and regenerate the Astro-Seek chart with the same birth inputs and explicit settings for numerical verification.

## Acceptance Criteria

- [ ] The wheel shows both lunar nodes, Lilith, Chiron, Part of Fortune and Vertex when applicable.
- [ ] The position table shows the additional entries represented as rows in the references, including ASC and MC.
- [ ] Each displayed position uses consistent sign, degree, minute and house values across views.
- [ ] Retrograde markers appear wherever the applicable calculated motion is retrograde.
- [ ] Retain the birth inputs, chart settings and reproduction results for each dated Astro-Seek example as evidence. Record any original settings that could not be independently confirmed.
- [ ] For each dated Whole Sign example whose original settings cannot be independently confirmed, use the original screenshot for display verification and generate a new Astro-Seek chart with the same birth inputs and explicit settings. Use the regenerated chart as the numerical reference for that dataset.
- [ ] The release evidence identifies every regenerated Astro-Seek chart and records its explicit settings.
- [ ] Adopt a calculation convention for each of the lunar nodes, Black Moon Lilith and Part of Fortune only when the numerical reproduction unambiguously confirms it. Agreement with a regenerated chart verifies the explicitly configured convention for that chart and leaves the original screenshot’s convention unconfirmed.
- [ ] If multiple definitions match at the displayed precision or the available evidence cannot distinguish between them, leave that point’s convention open for a separate decision under DEC-010.
- [ ] Record each confirmed definition in REQ-002 and use it as a matched setting in the REQ-005 numerical acceptance fixtures, which cover both original birth datasets.
