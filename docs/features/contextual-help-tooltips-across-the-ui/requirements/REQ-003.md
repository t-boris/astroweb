## Statement

On the profile screen and all end-user screens (profile creation, home, account, Premium/wallet, letters, compatibility), interactive controls and labels whose purpose is not self-evident — aspect filters, the house-system label, icon-only buttons, the Oracle indicators, paid features and credits — shall have a help bubble describing what they do. The admin screen is out of scope; the Astrologer notes page ("What your astrologer knows") is an end-user screen and is in scope (DEC-008).

## Acceptance Criteria

- [ ] Every icon-only button on the listed screens has a help bubble replacing or complementing the native title attribute.
- [ ] Aspect filters and the house-system label have help bubbles.
- [ ] Premium/credit (stars) and Oracle indicators (title, star cost, stars balance) have help bubbles that say the Oracle answer is written by an AI from the user's chart and costs one star, without naming a model (DEC-011).
- [ ] No help bubbles are added to the admin screen (pages/Admin.tsx and components/admin/*); a test fails if they are.
