## Question

Что делать с AI-текстами и чтениями, которые уже лежат только в localStorage у текущих пользователей?

## Why it matters

Без переноса пользователи после релиза «потеряют» уже оплаченные чтения на сервере, хотя на своём устройстве их видели.

## Options

- **A**: Автоматически выгрузить локальные данные на сервер при первом открытии профиля владельцем на этом устройстве
- **B**: Не переносить: новое хранится на сервере, старое остаётся видно только локально
- **C**: Не переносить и удалить локальные данные

## Recommended

A — Это сохраняет оплаченный контент. Риск подделки низкий: это тексты для самого пользователя, а не деньги.

## Answer

A. Автоматически выгрузить локальные данные на сервер при первом открытии профиля владельцем на этом устройстве
