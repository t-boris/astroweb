## Statement

Deep texts, compatibility readings and Oracle history stored on the server are deleted together with their profile, and an owner can delete a single Oracle entry or compatibility reading.

## Acceptance Criteria

- [ ] Deleting a profile through deleteProfile also removes every item under deepTexts/{profileId}, compatibilityReadings/{profileId} and oracleHistory/{profileId}; a test counts the remaining documents (zero).
- [ ] deleteProfile still rejects a caller who does not own the profile, and nothing is deleted in that case.
- [ ] deleteProfileContentItem removes exactly one Oracle entry or one compatibility reading by id for the profile's owner and leaves all other entries.
- [ ] deleteProfileContentItem rejects a caller who does not own the profile, and an id that belongs to another profile deletes nothing.
- [ ] In the UI, the delete button of an Oracle history entry or of a compatibility reading removes the entry on the server; after a reload and on another device it does not come back.
- [ ] For an anonymous user the same button removes the entry from localStorage only.
- [ ] Uploading local content never deletes or overwrites newer content that is already on the server.
