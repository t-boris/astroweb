## Context

'Describe the whole UI' spans dozens of screens; scope must be bounded.

## Alternatives

1. Profile screen only
2. Everything including admin and astrologer workspace

## Decision

Iteration 1 covers the profile screen and all end-user screens (profile creation, home, account, Premium/wallet, letters, compatibility); admin and astrologer workspace are excluded.

## Reason

Full coverage for end users; internal users do not need onboarding help.

## Consequences

Larger content and review effort than profile-only; internal screens remain without help.
