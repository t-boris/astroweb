## Statement

The system shall let the admin view and edit the prompt texts of each AI task, separately for each language the task has, with the data that the server inserts shown as named placeholders.

## Acceptance Criteria

- [ ] For each task the editor shows its system prompt and user-message template (DEC-011) for EN and RU where the task has both, or the single text where it has one; the same texts are used whichever provider runs the task (DEC-017)
- [ ] The editor lists the placeholders the task supports with a one-line description each (for example {{question}}, {{chart}}, {{dossier}}, {{language}})
- [ ] Saving is refused, with the missing or unknown names listed, when a required placeholder is missing or an unknown placeholder is used
- [ ] Saving is refused when a prompt text is empty or longer than 20,000 characters
- [ ] After a save, new requests of that task send the edited text with the placeholders filled, within 60 seconds
- [ ] The internal continuation prompt and the code that builds the inserted chart and profile data are not editable
