## Statement

The system shall send prompts containing personal data to OpenAI and Gemini only through request modes that do not keep conversation state on the provider's side.

## Acceptance Criteria

- [ ] Every OpenAI request sends store: false (unit test on the built request)
- [ ] Gemini requests use generateContent; the Interactions API is not used (unit test on the transport)
- [ ] The owner's setup instructions require a Gemini key from a billing-enabled project and name the three secrets to create
- [ ] API keys are read only from Secret Manager bindings, never logged, never written to functions/.env and never returned by any callable
