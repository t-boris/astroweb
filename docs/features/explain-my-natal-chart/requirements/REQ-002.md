## Statement

The system shall charge a signed-in user exactly one star per new picture, refund it when no birth is recovered or the AI fails, and return an earlier reading of the same picture without charging.

## Acceptance Criteria

- [ ] A signed-out caller is refused before any charge or AI call.
- [ ] Without a star the reading is refused and no model is called.
- [ ] One successful reading writes one chart_reading spend of 1 star; the same picture again charges nothing and calls no model.
- [ ] Every failure after the charge writes a refund row; the balance ends where it started.
- [ ] The story in each language is covered by the same star.
