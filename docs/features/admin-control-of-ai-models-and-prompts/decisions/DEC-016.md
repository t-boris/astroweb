## Context

Q-011. The letter news digest calls Claude with the web_search tool (max 2 searches) and expects a JSON answer.

## Alternatives

1. News digest limited to Claude models (recommended option A, not chosen)

## Decision

The news digest can run on any provider's model and uses that provider's own web search: Claude web_search tool, OpenAI web_search tool (Responses API), Gemini google_search grounding. The JSON answer format and the cap on searches per digest stay the same where the provider allows a cap.

## Reason

Answer of the owner to Q-011 (option B), 2026-10-18.

## Consequences

Search prices differ (OpenAI about $10 per 1,000 searches; Gemini 5,000 free searches a month, then about $14 per 1,000); a model without web search support is not offered for this task.
