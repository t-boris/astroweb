## Context

Models differ in the request parameters they accept: Opus 4.8 and newer reject `temperature`; Claude Opus 5.5 and Sonnet 5.5 always think, so thinking tokens count against max_tokens; refusals arrive as stop_reason "refusal". The OpenAI GPT-6 models are reasoning models (temperature only with reasoning effort none, which Astra and 6.1 Sol do not support; reasoning tokens count against max_output_tokens). Gemini 3.6 Flash and newer silently ignore temperature, all current Gemini models think by default and thinking tokens count against maxOutputTokens (official docs, 2026-10-18). A free-text model id or a blind switch can break a feature with HTTP 400 or truncated answers.

## Alternatives

1. Free-text model id (flexible, but any typo or unsupported parameter breaks production)
2. Live lists from the providers' model APIs (always current, but no per-model request rules and extra calls)

## Decision

A code module lists the models the admin may pick, for every provider (provider, id, label, input/output price with effective dates, whether temperature is accepted, thinking/reasoning behaviour, output limit, web search support). The server builds each request from the chosen model's rules: it drops parameters the model rejects, sets a safe thinking/effort setting and raises the output budget where thinking counts against it, and treats a refusal as an error. Unknown model ids are rejected on save and ignored on read (fallback to the default). Adding a model to the list needs a deploy. Initial list, ids checked against the providers' docs on 2026-10-18 and re-checked at implementation: Claude: claude-opus-4-8, claude-sonnet-4-6, claude-haiku-4-5 (in use today), claude-opus-5-5, claude-sonnet-5-5, claude-haiku-5-5. OpenAI: gpt-6-astra, gpt-6.1-sol, gpt-6-luna. Gemini: gemini-4-argon, gemini-3.8-flash, gemini-3.5-flash-lite. Announced price changes (Gemini 4 Argon from 2026-12-01, Gemini 3.8 Flash from 2027-01-01) are entered with their dates.

## Reason

Every model in the picker yields a valid request, and the price shown to the admin comes from one table that also feeds cost tracking (replaces the RATE table in claudeRaw.ts).

## Consequences

New Claude models appear in the picker only after a code change that adds their rules and a test.
