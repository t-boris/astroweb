## Question

Что входит в первую итерацию по охвату экранов?

## Why it matters

«Описание всего UI» — это десятки экранов (аккаунт, кошелёк, письма, админка, кабинет астролога); без границ скоуп не оценить.

## Options

- **A**: Только экран профиля: вкладки, термины, таблицы, элементы управления картой.
- **B**: Профиль + все пользовательские экраны (создание профиля, главная, аккаунт, Premium/кошелёк, письма, совместимость).
- **C**: Всё, включая админку и кабинет астролога.

## Recommended

A — Термины сосредоточены в профиле; остальное можно добавить следующими итерациями по тому же шаблону.

## Answer

B. Профиль + все пользовательские экраны (создание профиля, главная, аккаунт, Premium/кошелёк, письма, совместимость).
