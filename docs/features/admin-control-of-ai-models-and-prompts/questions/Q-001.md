## Question

Which AI providers should the admin be able to choose from: Claude models only, or also other providers (OpenAI, Gemini)?

## Why it matters

Today only Claude is used (raw HTTPS, ANTHROPIC_API_KEY). Other providers need new API keys in Secret Manager, a second transport (a new dependency or raw HTTP), different request parameters and prompts re-tuned per provider; that is an architecture change, while Claude-only needs none.

## Options

- **A**: Claude models only, from a server-side list; the data model keeps a provider field so another provider can be added later
- **B**: Claude plus OpenAI and/or Gemini in this feature

## Recommended

A

## Answer

B. Claude plus other providers (OpenAI and/or Gemini) in this feature. Answered by Boris in chat on 2026-10-18; the follow-up details (which providers, transport, web search, prompts per provider) are asked in Q-009..Q-012.
