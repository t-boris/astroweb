## Context

Q-003: without a test run, every change is first seen by real users.

## Alternatives

1. No test run; save and check on the site

## Decision

The admin can run a task once with the unsaved settings (model, limits, prompts) on a chosen profile, plus a sample question where the task needs one, and sees the answer, the model, the tokens used and the cost. A test run spends real API tokens, charges no stars, writes nothing to caches or to user content, and does not change the saved settings.
