## Context

Q-002: most behaviour (answer structure, length, tone) lives in the user-message template, not in the system prompt.

## Alternatives

1. System prompt only
2. Also the format of the inserted chart data

## Decision

For each task and language the admin edits the system prompt and the user-message template. Chart, profile and request data are inserted by the server through named placeholders such as {{question}} or {{chart}}; saving is refused when a required placeholder is missing or an unknown one is used. The format of the inserted data stays in code.

## Reason

Answer of the owner to Q-002 (option A), 2026-10-18.
