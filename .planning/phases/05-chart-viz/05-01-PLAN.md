1. **Create `web/src/components/chart/utils/chartMath.ts`:**

   Export these utility functions (from RESEARCH.md code examples):

   - `DEG_TO_RAD` constant (`Math.PI / 180`)
   - `eclipticToSvgAngle(eclipticDegree: number, ascDegree: number): number` — returns `180 - (eclipticDegree - ascDegree)`. Places ASC at 9 o'clock.
   - `polarToCartesian(cx: number, cy: number, radius: number, angleDeg: number): { x: number; y: number }` — standard conversion. **CRITICAL: Use `y: cy - radius * Math.sin(rad)` (subtract for SVG Y-inversion).**
   - `describeArc(cx: number, cy: number, radius: number, startAngle: number, endAngle: number): string` — SVG arc path string using `A` command. Set `largeArc = Math.abs(endAngle - startAngle) > 180 ? 1 : 0`. Sweep flag = `0` (counterclockwise).
   - `describeSector(cx: number, cy: number, innerRadius: number, outerRadius: number, startAngle: number, endAngle: number): string` — SVG sector path (annular wedge). Outer arc → line to inner → inner arc (reverse sweep) → close. Used for zodiac sign colored backgrounds.

   All functions are pure math, no React dependency.

3. **Create `web/src/api/charts.ts`:**

   Follow the same httpsCallable wrapper pattern as `web/src/api/profiles.ts`:

   ```typescript
   import { httpsCallable } from "firebase/functions";
   import { functions } from "@/lib/firebase";
   import type { ChartResult } from "@/types";

   interface GetChartPayload {
     profileId: string;
     ownerDeviceId: string;
     houseSystem?: "placidus" | "whole-sign";
   }

   interface GetChartResponse {
     cached: boolean;
     chart: ChartResult;
   }

   export async function getChart(
     profileId: string,
     ownerDeviceId: string,
     houseSystem: "placidus" | "whole-sign" = "placidus"
   ): Promise<GetChartResponse> {
     const fn = httpsCallable<GetChartPayload, GetChartResponse>(functions, "getChart");
     const result = await fn({ profileId, ownerDeviceId, houseSystem });
     return result.data;
   }
   ```

   Only expose `getChart` — it handles both cache-through and compute (backend already does this). No need for a separate `computeNatalChart` wrapper since `getChart` computes on cache miss.

   Props: `{ ascDegree: number }` — the ascendant ecliptic longitude, needed to rotate the ring.

   Render 12 zodiac sign sectors as annular wedges using `describeSector()`:
   - Each sign spans 30° of ecliptic longitude (Aries: 0-30, Taurus: 30-60, etc.)
   - Convert each sign's start/end degrees to SVG angles via `eclipticToSvgAngle(degree, ascDegree)`
   - Use `describeSector(cx, cy, zodiacInner, outerRadius, startAngle, endAngle)` for sector path
   - Fill each sector with its element color (`ELEMENT_COLORS[SIGN_ELEMENTS[sign]].fill`)
   - Stroke each sector border with element color at low opacity (`stroke={elementColor.stroke}`, `strokeOpacity={0.3}`, `strokeWidth={1}`)

   Place zodiac glyph at the midpoint of each sector:
   - Midpoint angle = `eclipticToSvgAngle(signStartDegree + 15, ascDegree)`
   - Glyph position = `polarToCartesian(cx, cy, (outerRadius + zodiacInner) / 2, midAngle)`
   - Render as `<text>` with the Unicode glyph, `fontSize={28}`, `textAnchor="middle"`, `dominantBaseline="central"`, `fill={elementColor.text}`

   Outer ring border circle: `<circle cx cy r={outerRadius} fill="none" stroke="rgba(255,255,255,0.15)" strokeWidth={1.5} />`

   Use `useMemo` to compute all sector paths + glyph positions (depends only on ascDegree).

2. **Create `web/src/components/chart/HouseCusps.tsx`:**

   Props: `{ cusps: number[], ascDegree: number, asc: number | null, mc: number | null }`

   Render 12 house cusp lines:
   - For each cusp `i` (0-11), convert `cusps[i]` to SVG angle via `eclipticToSvgAngle(cusps[i], ascDegree)`
   - Draw a line from `polarToCartesian(cx, cy, houseOuter, angle)` to `polarToCartesian(cx, cy, houseInner, angle)`
   - Stroke: `rgba(255, 255, 255, 0.2)`, strokeWidth: `1`
   - **ASC and MC lines get special treatment**: brighter stroke (`rgba(255, 255, 255, 0.5)`), strokeWidth `2`
   - ASC line: cusp index 0. MC line: cusp index 9 (MC cusp).

   Place house numbers:
   - For each house `i`, compute midpoint angle between `cusps[i]` and `cusps[(i+1) % 12]`
   - Handle 0/360 wrap: if `cusps[(i+1) % 12] < cusps[i]`, add 360 to the next cusp before averaging
   - Place number at `polarToCartesian(cx, cy, houseInner + 30, midAngle)` — slightly inside the house ring
   - Render as `<text>` with house number `i+1`, `fontSize={14}`, `fill="rgba(255,255,255,0.4)"`, `textAnchor="middle"`, `dominantBaseline="central"`

   Inner circle boundary: `<circle cx cy r={houseInner} fill="none" stroke="rgba(255,255,255,0.1)" strokeWidth={1} />`

   Use `useMemo` for all line + number positions.
