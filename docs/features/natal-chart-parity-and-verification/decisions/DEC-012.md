## Context

REQ-005 requires numerical verification against Astro-Seek for both dated Whole Sign examples. The screenshots may omit settings that affect the results, so the original settings may be impossible to confirm independently of the values under test.

## Alternatives

1. Require confirmation of the original settings for both dated screenshots and block release until both can be reproduced numerically.
2. Use a screenshot with unconfirmed settings for display verification and substitute a different, fully documented Whole Sign chart for its numerical comparison.

## Decision

If the original settings for a dated Whole Sign example cannot be independently confirmed, use its screenshot for display verification and generate a new Astro-Seek chart with the same birth inputs and explicit settings. Use the regenerated chart as the numerical reference.

## Reason

Regenerating the chart preserves both original birth datasets and makes the numerical comparisons reproducible without inferring settings from the values being tested.

## Consequences

Update REQ-005 to require numerical comparisons for both original birth datasets. The release evidence must identify any regenerated Astro-Seek chart and record the explicit settings used. Agreement with a regenerated chart does not confirm the original screenshot’s point conventions. Under DEC-010, any convention that remains ambiguous requires a separate decision.
