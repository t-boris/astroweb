2. **Implement `web/src/pages/ProfileDetail.tsx`:**
   - Import: `useParams`, `useNavigate`, `Link` from `react-router`
   - Import: `useTranslation` from `react-i18next`
   - Import: `useDeviceId` from `@/hooks/useDeviceId`
   - Import: `getProfile, deleteProfile` from `@/api/profiles`
   - Import: `Profile` from `@/types`
   - Import: Card components, Button, AlertDialog
   - Import: `FirebaseError` from `firebase/app`

   **State:**
   - `profile: Profile | null`
   - `loading: boolean` (true initially)
   - `error: string | null`
   - `showDeleteDialog: boolean`
   - `deleting: boolean`

   **On mount (useEffect):**
   - Extract `id` from useParams
   - Get deviceId from useDeviceId()
   - Call `getProfile(id, deviceId)`
   - On success: set profile
   - On error:
     - If `functions/not-found`: set error to "notFound"
     - Other: set generic error message
   - Set loading = false

   **Profile data display:**
   - Page title: profile name (h1)
   - Card with birth data section:
     - **Date**: formatted birthDate (use locale-aware formatting if simple, or just YYYY-MM-DD)
     - **Time**: birthTime or "Time unknown" (italic, muted) if timeUnknown
     - **Place**: birthPlace
     - **Timezone**: timezone (displayed from profile, was server-resolved)
     - **Coordinates**: `${lat.toFixed(4)}, ${lng.toFixed(4)}`
   - Use a simple definition-list or grid layout for label: value pairs

   **Action buttons:**
   - "Edit" button → navigates to `/profile/${id}/edit`
   - "Delete" button → opens AlertDialog
   - "Back to profiles" link → navigates to `/`

   **Delete flow (same as Home page):**
   - AlertDialog with confirmation message (includes profile name)
   - On confirm: call `deleteProfile(id, deviceId)` → navigate to `/`
   - On cancel: close dialog

   **Chart tab shell:**
   - Below the birth data card, add a section/div:
     - Placeholder text: `t("profile.detail.chartPlaceholder")`
     - This is where Phase 5 will add the tabbed view (Chart / Planets / Aspects / Interpretation)
     - Keep it minimal: just a card or bordered section with the placeholder text
     - Use a comment in code: `{/* Phase 5: Chart wheel, planets table, aspects table, interpretations */}`

   **States:**
   - Loading: show centered loading text
   - Error (not found): show error message with back link
   - Error (other): show generic error with back link
   - Success: show profile data + actions + chart placeholder
