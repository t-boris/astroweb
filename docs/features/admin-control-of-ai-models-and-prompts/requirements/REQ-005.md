## Statement

The system shall allow reading and changing AI settings only to the admin, checked on the server, and shall never send prompts or settings to other clients.

## Acceptance Criteria

- [x] Every AI-settings callable runs the same server check as the other admin callables (verified admin email) and returns permission-denied otherwise, covered by tests for a signed-out caller, a non-admin user and an unverified admin email
- [x] Firestore rules keep the settings collection inaccessible to clients
- [x] No end-user callable returns prompt texts or settings
- [x] Each save records who saved it and when
