## Statement

Server-stored readings, texts and history must be readable only by whoever is allowed to access the profile under the existing ownership rules, and only through backend functions.

## Acceptance Criteria

- [ ] Given a profile claimed by account X, when another account or an anonymous device requests its readings, then access is denied.
- [ ] Given any client, when it tries to read the stored content directly from the database, bypassing backend functions, then the request is rejected.
