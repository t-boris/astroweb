  <name>Task 1: Create astro/houses.ts and astro/chart.ts orchestrator</name>

  <action>
1. **Create `functions/src/astro/houses.ts`:**
   - Import `computeHouseCusps` from `./ephemeris`
   - Import `HOUSE_SYSTEM_CODES` from `./constants`
   - Import `ChartHouses` from `../types/index`

   - Export `calculateHouses(jd: number, lat: number, lng: number, system: 'placidus' | 'whole-sign'): ChartHouses`:
     - Look up system code from HOUSE_SYSTEM_CODES
     - Call computeHouseCusps(jd, lat, lng, systemCode)
     - Return ChartHouses object:
       - `system`: the input system name
       - `cusps`: the 12 cusp longitudes (array of 12 numbers)
       - `asc`: ascendant longitude (null if timeUnknown — but we don't know that here, always return it)
       - `mc`: MC longitude (same)

   - Export `findHouseForLongitude(lon: number, cusps: number[]): number`:
     - For **Whole Sign**: `Math.floor(((lon % 360) + 360) % 360 / 30) + 1` (but offset by ASC sign)
     - Actually, for simplicity and accuracy, use the cusp array regardless of system:
       - Iterate cusps 1-12. A planet is in house N if its longitude is between cusp[N] and cusp[N+1] (with cusp[13] wrapping to cusp[1]).
       - Handle wrap-around: if cusp[N] > cusp[N+1] (crossing 0°), the planet is in house N if lon >= cusp[N] OR lon < cusp[N+1].
     - Return house number 1-12.
     - **Alternative for accuracy:** If sweph provides `house_pos`, use that instead of manual calculation. Check if ephemeris.ts exposes it — if not, implement the cusp range logic above.

2. **Create `functions/src/astro/chart.ts`:**
   - Import `DateTime` from `luxon`
   - Import all astro modules: constants, ephemeris, zodiac, aspects, houses
   - Import types: `ChartResult, ChartPoint, ChartMeta` from `../types/index`

   - Export interface `ComputeChartInput`:
     ```typescript
     export interface ComputeChartInput {
       birthDate: string;       // YYYY-MM-DD
       birthTime: string | null; // HH:mm or null
       timeUnknown: boolean;
       lat: number;
       lng: number;
       timezone: string;        // IANA timezone
       houseSystem: 'placidus' | 'whole-sign';
     }
     ```

   - Export `computeNatalChart(input: ComputeChartInput): ChartResult`:
     **Pipeline steps:**

     **Step 1: Convert local time to UTC**
     - Parse birthDate as year, month, day
     - If timeUnknown: use 12:00 noon (standard astrological convention for unknown time)
     - Parse birthTime as hour, minute
     - Use luxon: `DateTime.fromObject({ year, month, day, hour, minute }, { zone: input.timezone }).toUTC()`
     - Extract UTC year, month, day, hour, minute
     - Convert to decimal hour: `utcHour + utcMinute / 60`

     **Step 2: Compute Julian Day**
     - Call `computeJulianDay(utcYear, utcMonth, utcDay, decimalHour)`

     **Step 3: Compute planetary positions**
     - Iterate BODIES array
     - For each body: call `calcPlanetPosition(jd, body.id)`
     - Convert longitude to zodiac: `longitudeToZodiac(position.longitude)`
     - Build ChartPoint (house is null for now — filled in step 5)

     **Step 4: Compute house cusps**
     - Call `calculateHouses(jd, input.lat, input.lng, input.houseSystem)`
     - If timeUnknown: set houses.asc = null, houses.mc = null (houses are unreliable without birth time)

     **Step 5: Assign planets to houses**
     - If NOT timeUnknown: for each ChartPoint, call `findHouseForLongitude(point.lon, houses.cusps)`
     - If timeUnknown: leave house as null

     **Step 6: Detect aspects**
     - Build points array for aspect detection: all 10 planets
     - If NOT timeUnknown: also include `{ name: 'ASC', lon: houses.asc }` and `{ name: 'MC', lon: houses.mc }`
     - Call `detectAllAspects(aspectPoints)`

     **Step 7: Build ChartResult**
     - meta: `{ houseSystem: input.houseSystem, zodiac: 'tropical', timeUsed: input.timeUnknown ? null : input.birthTime, timezoneUsed: input.timezone }`
     - points: ChartPoint array
     - houses: ChartHouses
     - aspects: ChartAspect array

   **Edge cases:**
   - timeUnknown: Use noon, but nullify house assignments and ASC/MC
   - Placidus at extreme latitudes (>66°): Let it compute (sweph handles it with interpolation), but if it errors, log and fall back to Whole Sign

1. **Create `functions/src/services/chart.ts`:**
   Follow the same pattern as services/profile.ts (Firestore admin SDK, ISO timestamps).

   - Import `getFirestore` from `firebase-admin/firestore`
   - Import `createHash` from `crypto`
   - Import `ChartDocument, ChartResult` from `../types/index`

   - Collection name: `"charts"`

   - Export `computeInputHash(inputs: { birthDate: string; birthTime: string | null; lat: number; lng: number; timezone: string; houseSystem: string }): string`:
     - Build canonical string: `[birthDate, birthTime ?? 'NULL', lat.toFixed(6), lng.toFixed(6), timezone, houseSystem].join('|')`
     - Return `createHash('sha256').update(canonical).digest('hex')`

   - Export `findCachedChart(profileId: string, inputHash: string): Promise<ChartDocument | null>`:
     - Query charts collection where `profileId == profileId` AND `inputHash == inputHash`
     - Return first match or null
     - Limit to 1 result

   - Export `storeChart(profileId: string, inputHash: string, result: ChartResult): Promise<ChartDocument>`:
     - Create new chart document with:
       - `profileId`
       - `type: 'natal'`
       - `computedAt: new Date().toISOString()`
       - `inputHash`
       - `result`
     - Return the full ChartDocument (including generated id)

   - Export `getChartByProfileId(profileId: string): Promise<ChartDocument | null>`:
     - Query charts collection where `profileId == profileId`
     - Order by `computedAt` descending
     - Limit 1
     - Return first match or null (returns most recent chart for a profile)

   - Export `deleteChartsByProfileId(profileId: string): Promise<void>`:
     - Query all charts for profileId
     - Delete in batch (use Firestore batch delete)
     - Useful for cleanup when profile is deleted

   **Patterns from profile.ts to follow:**
   - Use `getFirestore()` (lazy, not stored at module level)
   - ISO string for computedAt (not Firestore Timestamp)
   - Include doc.id as `id` in returned objects
  </action>
