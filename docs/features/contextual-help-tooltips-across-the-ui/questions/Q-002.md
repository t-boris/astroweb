## Question

Как подсказки должны открываться на телефонах и планшетах, где нет наведения мыши?

## Why it matters

Требование адаптивного UI есть в проекте; hover-only подсказки на тач-устройствах недоступны, а тап по элементу часто уже выполняет действие (переключает вкладку, фильтр).

## Options

- **A**: Наведение на десктопе; на тач-устройствах — нажатие с удержанием (long-press) на элементе.
- **B**: Маленькая иконка «?» / «i» рядом с элементом, открывается по нажатию на любом устройстве (на десктопе — также по наведению).
- **C**: Гибрид: на десктопе — наведение на сам элемент; на тач-устройствах — иконка «?» только там, где тап уже занят действием.

## Recommended

C — Сохраняет чистый интерфейс на десктопе и не ломает тапы по вкладкам и фильтрам на мобильных.

## Answer

C. Гибрид: на десктопе — наведение на сам элемент; на тач-устройствах — иконка «?» только там, где тап уже занят действием.
