## Question

Should every save keep a version (who, when, what changed) so the admin can see the history of a task and restore an earlier version, or is "reset to default" enough?

## Why it matters

A prompt edit goes straight to production. With history, a bad edit can be undone in one click to the last good text instead of only to the code default; without it the previous text is lost after a save. There is no admin audit log today.

## Options

- **A**: Version history per task with restore, plus reset to default
- **B**: Only the current value and reset to default

## Recommended

A

## Answer

B. Only the current value and reset to default; no version history. Answered by Boris in chat on 2026-10-18.
