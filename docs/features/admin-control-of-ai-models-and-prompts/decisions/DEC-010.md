## Context

Q-001: today the backend uses only Claude over raw HTTPS. The owner wants to pick models from other providers too.

## Alternatives

1. Claude models only, with a provider field for later (recommended option A, not chosen)

## Decision

The admin can choose, per AI task, a model from Claude or from another provider (OpenAI and/or Gemini; which providers, the transport, web search and prompts per provider are settled by Q-009..Q-012). Every provider sits behind one internal interface used by all call sites, so a task does not know which provider runs it.

## Reason

Answer of the owner to Q-001 (option B), 2026-10-18.

## Consequences

New API keys in Secret Manager, a transport per provider, per-model request rules for every provider, and prompts that may need re-tuning when a task moves to another provider.
