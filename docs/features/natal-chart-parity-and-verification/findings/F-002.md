## Finding

Agreement wherever the same aspect is shown permits either a shared aspect set or separate eligibility rules. The existing profile also has an Aspects list, which the requirement leaves out of this agreement. The choice determines whether a pair can qualify in one profile view and be absent from another, even with filters cleared.

> The wheel and matrix agree on point pairs, aspect types and orbs wherever the same aspect is shown.

## Possible interpretations

- Использовать единый набор рассчитанных аспектов для колеса, матрицы и списка. Видимость отдельных аспектов может зависеть от фильтров представления.
- Добавить матрицу с расширенными правилами Astro-Seek, сохранив существующие правила колеса и списка там, где это нужно для привычного представления.

## Resolution

Колесо, матрица и список используют один расширенный набор аспектов. Фильтры меняют только видимость. — see DEC-011.
