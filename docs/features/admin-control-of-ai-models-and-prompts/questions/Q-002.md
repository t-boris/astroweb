## Question

Which prompt text should be editable: only the system prompt, or also the instruction part of the user message (structure, length, tone), with chart and profile data inserted by the server through named placeholders?

## Why it matters

Most of the behaviour lives outside the system prompt today: e.g. the Oracle system prompt is ~600 characters while its user template (~1.7k) holds the answer structure and length rules; premium PDF section instructions (~2.7k) are in the user message. Editing only system prompts would leave most behaviour fixed in code.

## Options

- **A**: System prompt and user-message template, per language; data blocks are placeholders like {{question}} or {{chart}} that the server fills; saving is refused if a required placeholder is missing
- **B**: System prompt only; the user message stays in code
- **C**: As A, and also the format of the inserted chart data

## Recommended

A

## Answer

A. System prompt and user-message template, per language; data blocks are placeholders like {{question}} or {{chart}} that the server fills; saving is refused if a required placeholder is missing. Answered by Boris in chat on 2026-10-18.
