## Context

The supplied examples define the expected chart coverage. Existing tests check signs, ranges, and chart structure.

## Alternatives

1. Verify full charts against Astro-Seek and independently cross-check the longitudes of the ten standard bodies.
2. Use Astro-Seek as the sole calculation reference.

## Decision

Use Astro-Seek for full-chart verification and a separate ephemeris source independent of both Astro-Seek and AstroWeb’s calculation path for the longitudes of the ten standard bodies.

## Reason

Full-chart comparison checks reference parity. The independent comparison checks planetary longitudes through a separate calculation path.

## Consequences

Release evidence must include both a full-chart comparison under matched settings and an independent longitude comparison.
