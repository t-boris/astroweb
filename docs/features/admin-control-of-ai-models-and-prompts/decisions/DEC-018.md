## Context

Prompts carry personal data (names, birth date, time and place, questions, dossier facts). OpenAI's Responses API stores responses for 30 days unless `store: false` is sent. Google recommends the newer Interactions API for Gemini, which stores interactions by default (55 days on the paid tier); generateContent is called "legacy" but fully supported and stateless. Gemini free-tier content may be used to improve Google's products. Research of the official docs, 2026-10-18.

## Alternatives

1. OpenAI Chat Completions (supported, but Responses is the recommended API and the only one with the built-in web_search tool on current models)
2. Gemini Interactions API (recommended by Google for new projects, new features launch there first, but stores interactions by default)

## Decision

OpenAI calls use the Responses API (`responses.create`) with `store: false` and the system prompt in `instructions`. Gemini calls use `models.generateContent` with `systemInstruction`; the Interactions API is not used. The Gemini key must belong to a paid (billing-enabled) project. Thinking parts and reasoning items are never shown to users.

## Reason

Keeps users' birth data out of provider-side conversation storage beyond the providers' abuse-monitoring retention, with the simplest single-turn request shape on both APIs.

## Consequences

If Google retires generateContent or new Gemini models appear only on Interactions, the Gemini transport has to move and the storage setting must be revisited.
