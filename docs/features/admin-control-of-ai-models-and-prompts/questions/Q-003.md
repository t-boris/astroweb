## Question

Should the admin be able to test a changed model or prompt before saving it, by running the task once on a chosen profile and seeing the answer, tokens and cost?

## Why it matters

Without a test run, the only way to check a change is to save it to production and use the site, where real users get it at the same time. A test run spends real API tokens (no stars charged) and is the largest single part of the admin UI.

## Options

- **A**: Yes: 'Test' runs the unsaved settings on a chosen profile (and a sample question where the task needs one); nothing is charged, cached or saved to user content
- **B**: No test run in this feature; save and check on the site

## Recommended

A

## Answer

A. Yes: 'Test' runs the unsaved settings on a chosen profile (and a sample question where the task needs one); nothing is charged, cached or saved to user content. Answered by Boris in chat on 2026-10-18.
