## Question

Под какой язык оптимизировать SEO лендинга? Сейчас язык определяется на клиенте (localStorage/navigator), отдельных URL для языков нет, поэтому поисковик видит только английскую версию.

## Why it matters

Требование «title/description для EN/RU» при одном URL выполняется только для одного языка. От этого зависят sitemap, canonical/hreflang и то, в чьей выдаче будет сайт.

## Options

- **A**: Только EN: статические мета-теги на английском, RU-мета меняется на клиенте только для пользователей
- **B**: Только RU как основной язык для поисковиков
- **C**: Два публичных URL лендинга (/ и /ru) с hreflang, у каждого свои мета-теги

## Recommended

C — Приложение уже двуязычное, а отдельный URL для RU — единственный способ попасть в обе выдачи, не переходя на SSR.

## Answer

C. Два публичных URL лендинга (/ и /ru) с hreflang, у каждого свои мета-теги
