## Statement

The system shall keep the current models, limits and prompt texts as code defaults, shall behave exactly as today while no override is saved, and shall let the admin reset a task to its defaults.

## Acceptance Criteria

- [x] With no saved override, every task sends the same model, request parameters, system text and user text as before the feature (automated test per task and language)
- [x] The admin can view the default next to a custom value and reset the model, the limits or the prompts of a task to the default
- [x] A reset takes effect for new requests within 60 seconds
