## Question

The news digest for letters uses Claude's built-in web search tool. Should that task stay on Claude models only, or use each provider's own web search?

## Why it matters

Web search is a provider-specific server tool with its own request shape, result format and price (OpenAI web search tool, Gemini Google Search grounding). Supporting all three triples the work for one background task; restricting it keeps the task working as today.

## Options

- **A**: News digest offers only Claude models; all other tasks can use any provider
- **B**: News digest can use any provider, with that provider's web search

## Recommended

A

## Answer

B. News digest can use any provider, with that provider's web search. Answered by Boris in chat on 2026-10-18.
