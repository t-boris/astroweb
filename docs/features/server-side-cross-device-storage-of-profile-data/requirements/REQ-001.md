## Statement

A signed-in user must see the same list of profiles on every device and browser where they sign in with the same account, including profiles created anonymously on any device before that device's first sign-in (claimed on sign-in). Anonymous users without an account keep device-bound access only.

## Acceptance Criteria

- [ ] Profiles created on device A while signed in appear on device B after signing in with the same Google account.
- [ ] Anonymous profiles created on device A appear on device B after device A has signed in once with the account.
- [ ] An anonymous user on a new browser without sign-in does not see profiles from another browser.
