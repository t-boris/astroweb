<task type="auto">
  <name>Task 1: Create root monorepo structure with Firebase configuration</name>
  <files>package.json, .gitignore, firebase.json, .firebaserc, firestore.rules</files>
  <action>
Create the root project files:

1. **package.json** — Root package with npm workspaces:
   - `"name": "astroweb"`
   - `"private": true`
   - `"workspaces": ["web", "functions"]`
   - Scripts: `"dev": "firebase emulators:start"`, `"dev:web": "npm run dev --workspace=web"`, `"build:web": "npm run build --workspace=web"`, `"build:functions": "npm run build --workspace=functions"`, `"deploy": "npm run build:web && firebase deploy"`

2. **firebase.json** — Hosting + Functions + Firestore + Emulators:
   - hosting.public: `"web/dist"`, hosting.rewrites: SPA catch-all (`**` → `/index.html`), hosting.ignore standard patterns
   - functions: source `"functions"`, runtime `"nodejs22"`, codebase `"default"`
   - firestore.rules: `"firestore.rules"`
   - emulators: functions port 5001, firestore port 8080, hosting port 5173 (NOT 5000 — macOS AirPlay conflict), UI enabled on port 4000, singleProjectMode true

3. **.firebaserc** — Project alias:
   - `"default": "astroweb-dev"` (placeholder project ID, will be updated when Firebase project is created)

4. **firestore.rules** — Deny all direct access (security requirement):
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /{document=**} {
         allow read, write: if false;
       }
     }
   }
   ```

5. **.gitignore** — Standard ignores:
   - node_modules/, dist/, .firebase/, *.log, .env, .env.local, .env.*.local
   - firebase-debug.log, firestore-debug.log, ui-debug.log
   - .DS_Store, *.tsbuildinfo

Do NOT install firebase-tools globally — it should be used via npx. Do NOT create a Firebase project on Google Cloud (will be done separately when ready to deploy).
  </action>
  <verify>
- `cat package.json` shows workspaces config
- `cat firebase.json` shows emulators on correct ports (5001, 8080, 5173, 4000)
- `cat firestore.rules` shows deny-all rules
  </verify>
  <done>Root monorepo files exist with correct workspace configuration, Firebase emulator config on safe ports, and Firestore deny-all security rules.</done>
</task>

<task type="auto">
  <name>Task 2: Create Cloud Functions scaffold with Gen 2 setup</name>
  <files>functions/package.json, functions/tsconfig.json, functions/src/index.ts</files>
  <action>
Create the functions/ directory with:

1. **functions/package.json**:
   - `"name": "astroweb-functions"`
   - `"main": "lib/index.js"` (compiled output)
   - Dependencies: `firebase-functions` (latest, v7+), `firebase-admin` (latest, v13+)
   - DevDependencies: `typescript` (^5), `firebase-functions-test` (latest)
   - Scripts: `"build": "tsc"`, `"serve": "npm run build && firebase emulators:start --only functions"`, `"lint": "tsc --noEmit"`
   - Engine: `"node": "22"`

2. **functions/tsconfig.json**:
   - `"compilerOptions"`: target `"ES2022"`, module `"commonjs"` (Firebase Functions requires CommonJS), lib `["ES2022"]`, outDir `"./lib"`, rootDir `"./src"`, strict true, esModuleInterop true, skipLibCheck true, resolveJsonModule true, declaration true
   - `"include": ["src/**/*"]`

3. **functions/src/index.ts** — Starter function using Gen 2 API:
   - Import `onCall` from `firebase-functions/v2/https` (NOT Gen 1 `firebase-functions`)
   - Import `initializeApp` from `firebase-admin/app`
   - Call `initializeApp()`
   - Export a `hello` onCall function that returns `{ message: "Hello from AstroWeb!" }`
   - Add a comment noting Gen 2 is required for Node.js 22

Do NOT use Gen 1 imports (`import * as functions from "firebase-functions"`) — Gen 1 does not support Node.js 22. Do NOT use `functions.config()` — removed in v7, use params module instead when needed later.

After creating files, run `npm install` from the root to install all workspace dependencies.
  </action>

- `cd functions && npx tsc --noEmit` passes with no errors

- `ls functions/node_modules/firebase-functions` exists after npm install
  </verify>
  <done>Functions directory has valid TypeScript that compiles, uses Gen 2 API exclusively, targets Node.js 22, and installs without errors.</done>
</task>
