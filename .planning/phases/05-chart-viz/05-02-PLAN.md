  <action>
1. **Create `web/src/components/chart/PlanetMarkers.tsx`:**

   Props:
   ```typescript
   interface PlanetMarkersProps {
     points: ChartPoint[];
     ascDegree: number;
   }
   ```

   **Collision avoidance algorithm** (adapted from RESEARCH.md):

   Implement a `resolvePlanetCollisions` function (can be inline or in chartMath.ts):

   ```typescript
   interface PlacedPlanet {
     body: string;
     lon: number;           // Original ecliptic longitude
     svgAngle: number;      // SVG angle at base radius
     placedAngle: number;   // Adjusted angle after collision resolution
     radius: number;        // Final radius (may be offset outward)
     hasLeader: boolean;    // Whether leader line needed
   }
   ```

   Algorithm:
   - Convert each planet's `lon` to SVG angle via `eclipticToSvgAngle(lon, ascDegree)`
   - Sort by SVG angle
   - Iterate: for each planet, check angular distance to all already-placed planets at the same radius
   - If angular distance < `minSeparationDeg` (8°) at the same radius, push outward by `offsetStep` (30 units in viewBox), set `hasLeader = true`
   - Result: array of PlacedPlanet with final positions

   **Rendering:**

   For each placed planet:

   a. **Leader line** (if `hasLeader`):
      - Thin line from the planet's ecliptic position at `planetRadius` to the placed position at `radius`
      - Both points computed via `polarToCartesian(cx, cy, r, angle)`
      - Stroke: `rgba(255, 255, 255, 0.2)`, strokeWidth: `0.5`

   b. **Planet glyph**:
      - Position: `polarToCartesian(cx, cy, placed.radius, placed.placedAngle)`
      - Render as `<text>` with Unicode glyph from `PLANET_GLYPHS[body]`
      - `fontSize={22}`, `textAnchor="middle"`, `dominantBaseline="central"`
      - `fill="white"` — white glyphs on dark background for maximum readability
      - Apply `filter="url(#glow)"` for the cosmic glow effect (filter defined in NatalChart's `<defs>`)

   c. **Invisible touch target**:
      - `<circle>` at the same position, `r={20}`, `fill="transparent"`, `pointerEvents="all"`
      - This ensures planets are easily clickable/tappable (44px equivalent at typical chart sizes)
      - Add `data-planet={body}` attribute for later hover handling in 05-03

   d. **Degree label** (small, below/beside glyph):
      - Show `degreeInSign` formatted as `${Math.floor(degreeInSign)}°` in a tiny `<text>`
      - Position slightly outward from the glyph: `polarToCartesian(cx, cy, placed.radius + 18, placed.placedAngle)`
      - `fontSize={10}`, `fill="rgba(255, 255, 255, 0.5)"`

   Wrap each planet's elements in a `<g>` group with `className="planet-group"` and `data-planet={body}`.

   Use `useMemo` for collision resolution (depends on `points` and `ascDegree`).

   **Important:** The function should be a `<g>` element (not a fragment) so NatalChart can render it inside the SVG. All child elements must be valid SVG elements — no HTML.

1. **Create `web/src/components/chart/AspectLines.tsx`:**

   Props:
   ```typescript
   interface AspectLinesProps {
     aspects: ChartAspect[];
     points: ChartPoint[];
     ascDegree: number;
   }
   ```

   **Rendering:**

   For each aspect in `aspects`:

   a. Find the ecliptic longitude of body A and body B from `points` array (match by `body` name)
   b. Convert both to SVG angles: `eclipticToSvgAngle(lonA, ascDegree)` and `eclipticToSvgAngle(lonB, ascDegree)`
   c. Compute screen positions: `polarToCartesian(cx, cy, aspectRadius, angleA)` and same for B
   d. Draw a `<line>` connecting the two points
   e. Style:
      - `stroke={ASPECT_COLORS[aspect.type]}`
      - `strokeWidth={1 + aspect.exactness}` — more exact aspects are slightly thicker (range 1-2)
      - `strokeOpacity={0.3 + aspect.exactness * 0.4}` — more exact aspects are more visible (range 0.3-0.7)
      - Apply `filter="url(#line-glow)"` for subtle glow on the dark background
   f. Add `data-aspect-type={aspect.type}`, `data-aspect-a={aspect.a}`, `data-aspect-b={aspect.b}` attributes for later filtering/hover in 05-03

   Wrap all lines in a `<g className="aspect-lines">`.

   Use `useMemo` to compute all line positions (depends on `aspects`, `points`, `ascDegree`).

   **Optimization:** Build a lookup map `bodyToLon: Record<string, number>` from `points` at the start, rather than searching the array for each aspect.
