## Statement

Add the pairwise aspect matrix and support the aspect information shown in the supplied charts. Use one shared, expanded set of calculated aspects across the natal wheel, aspect matrix, and Aspects list. Filters change only which aspects are visible.

## Acceptance Criteria

- [ ] The reference inventory maps every visible major and minor aspect glyph to a supported aspect type.
- [ ] The natal wheel, aspect matrix, and Aspects list use one shared, expanded set of calculated aspects.
- [ ] With all filters cleared, the natal wheel, aspect matrix, and Aspects list show the same qualifying point pairs and aspect types.
- [ ] The aspect matrix displays the qualifying point pairs, aspect glyphs, orbs, and applying or separating status where applicable.
- [ ] Orb values match across the three views wherever they are displayed for the same aspect.
- [ ] Applying or separating status matches across the three views wherever it is applicable and displayed for the same aspect.
- [ ] Toggling a filter changes only which aspects are visible. The shared calculated set and its point pairs, aspect types, orbs, and applying or separating statuses stay the same.
