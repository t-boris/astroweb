## Statement

The system shall not store the uploaded picture, shall keep a reading only for the user who uploaded it, and shall not ask the model for the name or birth data printed on the picture.

## Acceptance Criteria

- [x] The stored reading holds the read positions, the recovered birth, the chart and the stories, and no part of the picture.
- [x] Another user asking for the story of a reading gets 'not found', the same as for a missing reading.
- [x] The reading prompt tells the model not to report a name, birth date, time or place; the server keeps only the fields of its schema.
- [x] Readings are not readable from the client (Firestore rules deny by default).
