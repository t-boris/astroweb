## Question

The overview and REQ-003 expect a help bubble on the Oracle "AI model label", but no model label is shown anywhere in the UI. What should the Oracle model help be?

## Why it matters

Checked: overview understanding note on Acceptance Criteria ("Models" read as house systems and the Oracle AI model label, modelLabel), REQ-003 statement ("AI model labels") and AC3 ("Premium/credit (stars) and Oracle model indicators have help bubbles"), plan I-5 ("Oracle/AI model labels"). In the code, the i18n key ai.modelLabel ("Model: {{model}}") has zero usages in web/src; the model name is stored with each answer (response.model) but never rendered, and no feature is labelled as AI-generated. The Oracle tab shows a title, a description, a "Stars - 1" cost label and a stars balance pill. Showing the model name would be new UI and a product choice about disclosing the vendor model.

## Options

- **A**: Keep the UI as it is (no model name). The 'Oracle indicators' are the Oracle title, its cost label and the stars balance pill; their help says the answer is written by an AI from your chart and costs one star. 'Model label' in REQ-003 becomes 'Oracle indicators'.
- **B**: Show a small 'Model: <name>' label on each Oracle answer (the existing, unused ai.modelLabel key) with a help bubble. This exposes the AI model name to users.
- **C**: No Oracle-specific help beyond the stars indicators; drop the model wording from REQ-003.

## Recommended

A

## Answer

A. Keep the UI as it is (no model name). The Oracle indicators are the Oracle title, its star-cost label and the stars balance pill; their help says the answer is written by an AI from your chart and costs one star.
