## Statement

The system shall not serve a cached AI answer that was produced with earlier settings of its task, while leaving content already saved for users unchanged.

## Acceptance Criteria

- [x] The cache keys of deeper interpretation, forecast, premium PDF and news digest include the settings version of their task
- [x] After a save, the next request for a cached item generates a new answer with the new settings
- [x] With no override, existing cache entries remain valid after the release (no mass regeneration)
- [x] Oracle history, compatibility readings, letters and previously generated PDFs are not modified
