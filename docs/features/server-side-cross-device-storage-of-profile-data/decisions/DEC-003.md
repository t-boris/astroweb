## Context

DEC-001 keeps anonymous free usage, with sign-in required only before paid actions. That leaves free anonymous profiles tied to the browser's deviceId: they are lost if the user changes browser or clears storage.

## Alternatives

1. Show nothing and rely on the sign-in prompt at the first paid action

## Decision

Show anonymous users an unobtrusive banner or hint in the profile list. It explains that their profiles are stored only in this browser and offers a 'Sign in to save' action that starts the existing Google sign-in and profile-claim flow.

## Reason

It costs little and removes the only remaining data-loss scenario the user is not aware of. It also nudges users toward signing in.

## Consequences

One more UI element in the profile list for anonymous users. Signed-in users never see it. After sign-in, the existing claimProfiles flow attaches the device's profiles to the account.
