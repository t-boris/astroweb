## Context

Q-009, follow-up to Q-001/DEC-010.

## Alternatives

1. Only OpenAI
2. Only Gemini

## Decision

The model list covers three providers: Anthropic Claude, OpenAI and Google Gemini (Gemini Developer API with an API key). A provider's models can be chosen only when its API key is configured on the server (ANTHROPIC_API_KEY, OPENAI_API_KEY, GEMINI_API_KEY in Secret Manager); otherwise they are shown as unavailable.

## Reason

Answer of the owner to Q-009 (option A), 2026-10-18.

## Consequences

The owner creates OPENAI_API_KEY and GEMINI_API_KEY in Secret Manager (a paid-tier Gemini key, see the privacy requirement); the functions that run AI tasks bind all three secrets.
