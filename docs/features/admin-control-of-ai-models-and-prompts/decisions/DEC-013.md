## Context

Q-004: a version per save with restore was offered.

## Alternatives

1. Version history per task with restore, plus reset to default (recommended option A, not chosen)

## Decision

Only the current settings of each task are stored (with who saved them and when). The admin can reset a task to its code defaults; there is no history of earlier saved versions and no restore of a previous custom text.

## Reason

Answer of the owner to Q-004 (option B), 2026-10-18.

## Consequences

A saved edit overwrites the previous custom text; only the code default can be restored. The settings version used for cache keys (DEC-004) is a content hash or counter on the current document, not a history.
