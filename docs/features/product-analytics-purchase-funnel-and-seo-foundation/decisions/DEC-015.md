## Context

REQ-004, REQ-005 and REQ-008 need unit tests of pure web modules (route metadata and sitemap, consent store, event payload builders, privacy text rules), but the web workspace has no test runner. The project rule is not to change libraries without approval. vitest ^4.0.18 is already used by functions and is already in the root lockfile. Approved by the owner on 2026-10-12.

## Alternatives

1. Run the web tests inside the functions vitest by importing the web modules across workspaces (needs a tsconfig exclude and crosses package boundaries)

## Decision

web/package.json gets devDependency vitest ^4.0.18 and a script `test` = `vitest run`. The tests cover pure TypeScript modules only (no DOM or React rendering). The PR-check workflow runs them.

## Reason

Same tool and version as functions, no new runtime code, and the cleanest place for web tests.

## Consequences

One devDependency line and one script in web/package.json; the root package-lock.json records the workspace dependency. No runtime bundle change.
