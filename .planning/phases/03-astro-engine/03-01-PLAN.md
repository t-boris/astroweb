1. **Create `functions/src/astro/zodiac.ts`:**
   - Import `ZODIAC_SIGNS` from `./constants`
   - Export `longitudeToZodiac(lon: number): { sign: string; degreeInSign: number }`:
     - Normalize longitude: `const normalized = ((lon % 360) + 360) % 360;`
     - Sign index: `Math.floor(normalized / 30)`
     - Degree in sign: `normalized % 30` (keep full decimal precision)
     - Return `{ sign: ZODIAC_SIGNS[signIndex], degreeInSign }`
   - Export `longitudeToSign(lon: number): string` — convenience wrapper, returns just the sign name

2. **Create `functions/src/astro/aspects.ts`:**
   - Import `ASPECT_DEFINITIONS` from `./constants`
   - Import `ChartAspect` from `../types/index`
   - Export `angularDifference(lon1: number, lon2: number): number`:
     - `const raw = Math.abs(lon1 - lon2) % 360;`
     - `return raw > 180 ? 360 - raw : raw;`
     - This handles the 0°/360° wrap-around correctly
   - Export `detectAspect(nameA: string, lonA: number, nameB: string, lonB: number): ChartAspect | null`:
     - Compute angular difference
     - Iterate ASPECT_DEFINITIONS
     - For each, check if `Math.abs(diff - def.angle) <= def.orb`
     - If match: return `{ a: nameA, b: nameB, type: def.type, orb: Math.round(deviation * 100) / 100, exactness: Math.round((1 - deviation / def.orb) * 100) / 100 }`
     - If no match: return null
   - Export `detectAllAspects(points: Array<{ name: string; lon: number }>): ChartAspect[]`:
     - Triangular iteration: for i=0..n-1, for j=i+1..n-1
     - This avoids duplicate pairs (Sun-Moon and Moon-Sun)
     - Call detectAspect for each pair
     - Collect non-null results
     - Sort by exactness descending (most exact first)
     - The `points` array should include all 10 planets PLUS ASC and MC (12 points total, 66 pairs)

   **Type alignment:** Ensure ChartAspect.type matches the union type in types/index.ts: `"conjunction" | "opposition" | "trine" | "square" | "sextile"`. The ASPECT_DEFINITIONS use `as const` to ensure this.
