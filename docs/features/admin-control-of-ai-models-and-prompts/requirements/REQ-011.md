## Statement

The system shall run each AI task on the model chosen for it from any of the three providers (Claude, OpenAI, Gemini), with the same prompts, the same output handling and the provider's own web search for the news digest.

## Acceptance Criteria

- [ ] Every task (including letter analysis, letter writing and fact extraction, which expect JSON) produces a valid result on at least one model of each provider, verified by a test run per provider before release
- [x] A truncated answer is detected for every provider (Claude stop_reason max_tokens, OpenAI status incomplete with reason max_output_tokens, Gemini finishReason MAX_TOKENS) and handled like today's continuation or reported as an error
- [x] A refusal or safety block (Claude refusal, OpenAI refusal content or content_filter, Gemini SAFETY / PROHIBITED_CONTENT / promptFeedback.blockReason) fails the request with a clear log entry and the same star refund as other failures
- [x] Reasoning or thinking content is never included in the text shown to users
- [ ] The news digest uses the chosen provider's web search (Claude web_search, OpenAI web_search, Gemini google_search) and returns the same JSON structure as today; models without web search support are not offered for that task
- [x] Models of a provider whose API key is not configured are shown as unavailable and cannot be saved; a request never falls back silently to another provider
- [x] Token usage of every call is recorded where it is recorded today (letters, letter jobs) and cost is computed from the shared model price table for all providers
