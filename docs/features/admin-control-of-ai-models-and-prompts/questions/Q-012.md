## Question

Should a task have one set of prompts used by whichever model runs it, or a separate set of prompts per provider?

## Why it matters

Today's prompts are tuned for Claude. One shared set is simpler to maintain (switch the model, test, adjust the text if needed); separate sets let each provider keep its own tuned text but triple the texts to edit and keep in sync.

## Options

- **A**: One set per task and language, shared by every model; after switching provider the admin tests and adjusts it
- **B**: A separate set per provider for each task and language

## Recommended

A

## Answer

A. One set per task and language, shared by every model; after switching provider the admin tests and adjusts it. Answered by Boris in chat on 2026-10-18.
