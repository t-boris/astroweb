## Context

Personal lines would require chart data and could expose paid content.

## Alternatives

1. Generic definition plus a personal line from interpretation templates

## Decision

Help texts are static generic definitions identical for all users; no chart-specific or AI-generated content.

## Reason

Solves UI understanding without overlapping paid interpretations.

## Consequences

Content is pure static i18n text; no chart data access in help components.
