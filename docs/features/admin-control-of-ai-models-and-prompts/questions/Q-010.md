## Question

How should the backend call the new providers: raw HTTPS like the Claude calls today, or the providers' official SDK packages?

## Why it matters

The Claude integration deliberately uses raw HTTPS with no SDK. Official SDKs (openai, @google/genai) are new dependencies; Cloud Build installs functions/package.json without a lockfile, so unpinned SDK updates can change behaviour on any deploy. Raw HTTPS keeps one pattern and no new dependency, at the cost of writing the request/response mapping per provider.

## Options

- **A**: Raw HTTPS per provider behind one internal interface, like Claude today; no new dependencies
- **B**: Official SDKs for OpenAI and Gemini (pinned versions); Claude stays on raw HTTPS

## Recommended

A

## Answer

B. Official SDKs for OpenAI and Gemini (pinned versions); Claude stays on raw HTTPS. Answered by Boris in chat on 2026-10-18.
