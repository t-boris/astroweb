## Statement

The system shall fall back to the code defaults of a task, and log a warning, when its stored settings cannot be read or are invalid.

## Acceptance Criteria

- [ ] If reading the settings fails, the task runs with its defaults and the request succeeds as it does today
- [ ] A stored model id that is not in the model list, a missing required placeholder or an out-of-range limit makes that task use its defaults for the invalid part, with a warning in the function logs
- [ ] Settings are read at most once per minute per function instance (in-memory cache), so the feature adds no noticeable latency to AI requests
