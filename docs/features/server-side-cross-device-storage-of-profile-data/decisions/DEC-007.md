## Context

discussion.md (point 2) asked what happens to the stored texts, readings and Oracle history when a profile is deleted, and had no answer. functions/src/api/deleteProfile.ts deletes only the profile document, and compatibility readings contain the partner's name, birth date and birth place. forgetDossier already deletes oracleHistory. Answered by the owner on 2026-10-12.

## Alternatives

1. Keep the content after the profile is gone (unreachable but stored forever, including third-party data)

## Decision

deleteProfile also deletes deepTexts/{profileId}, compatibilityReadings/{profileId} and oracleHistory/{profileId} (all items). The deletion happens after the ownership check and before the profile document is removed, in the same callable.

## Reason

No orphaned personal data, consistent with forgetDossier, and the user deleted the profile on purpose.

## Consequences

Paid content disappears together with a profile the user deletes. The profile UI mostly archives instead of deleting, so archived profiles keep their content. Covered by a test that counts remaining documents.
