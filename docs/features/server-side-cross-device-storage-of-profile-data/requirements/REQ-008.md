## Statement

When an anonymous user views their profile list, the app must show an unobtrusive notice. It must say that their profiles are stored only in this browser and may be lost if they switch browser or clear its data, and it must offer a 'Sign in to save' action that starts Google sign-in and claims this device's profiles to the account.

## Acceptance Criteria

- [ ] An anonymous user who has at least one profile sees the notice in the profile list.
- [ ] A signed-in user never sees the notice.
- [ ] Activating 'Sign in to save' starts Google sign-in. On success, the device's anonymous profiles are claimed to the account through the existing claimProfiles flow and the notice disappears.
- [ ] The notice does not block creating, opening or using profiles.
