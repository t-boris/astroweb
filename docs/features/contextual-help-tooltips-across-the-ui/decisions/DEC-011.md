## Context

The overview, REQ-003 and plan I-5 expect a help bubble on the Oracle AI model label (modelLabel). In the code ai.modelLabel has no usages; response.model is stored with each answer but never rendered.

## Alternatives

1. Show a 'Model: <name>' label on each Oracle answer with a help bubble (exposes the AI model name to users)
2. Drop the model wording and give no Oracle-specific help beyond the stars indicators

## Decision

No AI model name is added to the UI. The "Oracle model indicators" of REQ-003 are the Oracle title, its star-cost label and the stars balance pill; their help bubbles say that the answer is written by an AI from the user's chart and costs one star. The unused ai.modelLabel string stays unused.

## Reason

Answer to Q-009 (A, 2026-10-13). The model label does not exist in the UI today; showing the vendor model name is a product choice that was not asked for, and the explanation of what the Oracle is serves the user better than a model name.

## Consequences

REQ-003 statement and AC3 and plan I-5 say "Oracle indicators" instead of "model label". Help texts must not name a model or vendor.
