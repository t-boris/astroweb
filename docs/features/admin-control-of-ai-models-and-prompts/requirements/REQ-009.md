## Statement

The system shall let the admin run an AI task once with unsaved settings on a chosen profile and show the answer, the model, the tokens used and the cost, without charging, caching or saving anything.

## Acceptance Criteria

- [x] Each task in the AI tab has a Test action that uses the settings currently in the editor, saved or not
- [x] The admin picks a profile from the existing profiles list; tasks that need extra input (Oracle and Oracle in letters: a question; Deeper interpretation: a topic; Compatibility: a second profile) ask for it, with a sensible sample prefilled
- [x] The result shows the generated text, the model id that answered, input and output tokens, the cost in USD from the model price table, and the time taken
- [x] A test run charges no stars and writes nothing to result caches, Oracle history, compatibility readings, letters, dossiers or the saved settings
- [x] A failed test run (API error, refusal, missing API key) shows the error message instead of a result
- [x] Only the admin can start a test run (same server check as REQ-005)
