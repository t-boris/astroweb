## Question

Отслеживать ли в аналитике, какие подсказки открывают пользователи?

## Why it matters

В проекте строгая GA4-таксономия событий с белым списком параметров; новое событие нужно добавить явно. Данные покажут, какие термины непонятны.

## Options

- **A**: Не отслеживать.
- **B**: Событие «help_opened» с ключом подсказки (без PII), только при наличии согласия.

## Recommended

B — Дешёвый сигнал о том, где UI непонятен, в рамках существующих правил согласия.

## Answer

A. Не отслеживать.
