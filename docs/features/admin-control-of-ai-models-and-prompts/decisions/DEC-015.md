## Context

Q-010. Claude is called over raw HTTPS without an SDK; Cloud Build installs functions/package.json without a lockfile.

## Alternatives

1. Raw HTTPS for every provider, no new dependencies (recommended option A, not chosen)

## Decision

OpenAI is called through the official `openai` package and Gemini through `@google/genai`, each pinned to an exact version (no caret range) published at least two weeks before it is added. Claude keeps its raw HTTPS transport. All three sit behind one internal provider interface (generate text with system prompt, user message, output limit, optional temperature, optional JSON output, optional web search; returns text, model, token usage, stop reason).

## Reason

Answer of the owner to Q-010 (option B), 2026-10-18. Exact pins keep deploys reproducible without a lockfile. The functions runtime is nodejs22, which the current openai SDK requires.

## Consequences

Two new runtime dependencies in functions/package.json; SDK upgrades are deliberate code changes.
