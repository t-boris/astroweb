<task type="auto">
  <name>Task 1: Create computeNatalChart and getChart Cloud Functions</name>
  <files>functions/src/api/computeNatalChart.ts, functions/src/api/getChart.ts</files>
  <action>
1. **Create `functions/src/api/computeNatalChart.ts`** — `onCall` Gen 2:
   - Import `onCall, HttpsError` from `firebase-functions/v2/https`
   - Import `computeNatalChart` from `../astro/chart`
   - Import `* as profileService` from `../services/profile`
   - Import `* as chartService` from `../services/chart`

   - Extract from request data: `profileId` (string), `ownerDeviceId` (string), `houseSystem` (optional, default `'placidus'`)
   - Validate:
     - `profileId`: non-empty string, else `HttpsError("invalid-argument", "profileId is required")`
     - `ownerDeviceId`: non-empty string, else `HttpsError("invalid-argument", "ownerDeviceId is required")`
     - `houseSystem`: if provided, must be `'placidus'` or `'whole-sign'`, else `HttpsError("invalid-argument", "Invalid house system")`

   - **Ownership check:** Fetch profile by ID, verify ownerDeviceId matches
     - Not found → `HttpsError("not-found", "Profile not found")`
     - Mismatch → `HttpsError("permission-denied", "Access denied")`

   - **Cache check:** Compute inputHash from profile data + houseSystem, call `chartService.findCachedChart(profileId, inputHash)`
     - If cache hit: return the cached ChartResult directly (skip computation)

   - **Compute:** Call `computeNatalChart({ birthDate: profile.birthDate, birthTime: profile.birthTime, timeUnknown: profile.timeUnknown, lat: profile.lat, lng: profile.lng, timezone: profile.timezone, houseSystem })`

   - **Store:** Call `chartService.storeChart(profileId, inputHash, result)`

   - **Return:** The ChartResult object

   - **Error handling:** Wrap in try/catch, unexpected errors → `HttpsError("internal", "Failed to compute chart")`

2. **Create `functions/src/api/getChart.ts`** — `onCall` Gen 2:
   - Import same modules as computeNatalChart

   - Extract from request data: `profileId` (string), `ownerDeviceId` (string), `houseSystem` (optional, default `'placidus'`)
   - Same validation as computeNatalChart

   - **Ownership check:** Same pattern — fetch profile, verify ownerDeviceId

   - **Cache-through pattern:**
     1. Compute inputHash from profile data + houseSystem
     2. Call `chartService.findCachedChart(profileId, inputHash)`
     3. If cache hit: return `{ cached: true, chart: cachedDoc.result }`
     4. If cache miss:
        - Compute chart: `computeNatalChart({ ... profile fields ..., houseSystem })`
        - Store chart: `chartService.storeChart(profileId, inputHash, result)`
        - Return `{ cached: false, chart: result }`

   - The difference from computeNatalChart: getChart returns a wrapper with `cached` boolean, making it clear to the client whether this was a fresh computation.

   - **Error handling:** Same pattern as other Cloud Functions

   **Follow existing Cloud Function patterns from createProfile.ts:**
   - Gen 2 imports: `import { onCall, HttpsError } from "firebase-functions/v2/https"`
   - Same error code conventions: invalid-argument, not-found, permission-denied, internal
   - Thin function body: delegates to service/computation layers
