## Summary

The user's original request: they believe the app stores all of a user's profiles locally in browser localStorage. They say this is wrong. Profiles should be stored in the database so the user sees their profiles no matter where they sign in from. The code shows profile records are already in Firestore, so the premise is only partly accurate; the real device-bound gaps are the anonymous deviceId and the per-profile AI content.

## Origin

intake

## Content

На данный момент на том месте хранит все свои профили локально, в Local Storage, в браузере. Это неправильно. Нужно сделать так, чтобы он хранил это в базе данных. И чтобы неважно откуда ты логинишься, ты видел свои профили.
