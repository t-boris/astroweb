## Context

Hover-on-element could annoy experienced users.

## Alternatives

1. 'Show hints' toggle in account settings, on by default

## Decision

Help bubbles are always available; no user setting to disable them.

## Reason

Delayed hover / on-demand opening is unobtrusive; a toggle can be added later if needed.

## Consequences

No preference storage; desktop hover must use an open delay to stay unobtrusive.
