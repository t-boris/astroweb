## Statement

Calculate and display the additional natal points and motion indicators visible across the reference charts. Use the dated Astro-Seek examples to verify the calculation conventions for the lunar nodes, Black Moon Lilith and Part of Fortune, adopting a convention for each point only when the numerical reproduction unambiguously confirms it. If the original settings for a dated Whole Sign example cannot be independently confirmed, use its screenshot for display verification and regenerate the Astro-Seek chart with the same birth inputs and explicit settings for numerical verification.

Confirmed definitions (evidence in docs/verification/natal-chart-parity.md, section 5; each agrees with the regenerated Astro-Seek charts A to D at arcsecond resolution):

- Lunar nodes: the mean North Node, and the South Node 180 degrees opposite it. The true node misses by 68 to 102 arcminutes.
- Black Moon Lilith: the mean lunar apogee. The osculating and interpolated apogees miss by 69 to 1542 arcminutes.
- Chiron: Swiss Ephemeris Chiron from the bundled seas_18.se1 (DEC-015), available for birth dates from 1800 to 2400.
- Part of Fortune: day formula (ASC + Moon - Sun) when the Sun is above the true horizon, night formula (ASC + Sun - Moon) otherwise (DEC-016, chosen by the owner after the evidence excluded the always-day rule and the Sun-in-house rule).
- Vertex, house cusps, ASC and MC: from the Swiss Ephemeris ARMC with the mean obliquity of the ecliptic (DEC-018). With the true obliquity the Vertex misses by up to 28 arcseconds and the quadrant cusps by up to 6.4 arcseconds.
- Retrograde marker: longitude speed below zero; Part of Fortune and Vertex have no motion marker.

## Acceptance Criteria

- [x] The wheel shows both lunar nodes, Lilith, Chiron, Part of Fortune and Vertex when applicable.
- [x] The position table shows the additional entries represented as rows in the references, including ASC and MC.
- [x] Each displayed position uses consistent sign, degree, minute and house values across views.
- [x] Retrograde markers appear wherever the applicable calculated motion is retrograde.
- [x] Retain the birth inputs, chart settings and reproduction results for each dated Astro-Seek example as evidence. Record any original settings that could not be independently confirmed.
- [x] For each dated Whole Sign example whose original settings cannot be independently confirmed, use the original screenshot for display verification and generate a new Astro-Seek chart with the same birth inputs and explicit settings. Use the regenerated chart as the numerical reference for that dataset.
- [x] The release evidence identifies every regenerated Astro-Seek chart and records its explicit settings.
- [x] Adopt a calculation convention for each of the lunar nodes, Black Moon Lilith and Part of Fortune only when the numerical reproduction unambiguously confirms it. Agreement with a regenerated chart verifies the explicitly configured convention for that chart and leaves the original screenshot’s convention unconfirmed.
- [x] If multiple definitions match at the displayed precision or the available evidence cannot distinguish between them, leave that point’s convention open for a separate decision under DEC-010.
- [x] Record each confirmed definition in REQ-002 and use it as a matched setting in the REQ-005 numerical acceptance fixtures, which cover both original birth datasets.
