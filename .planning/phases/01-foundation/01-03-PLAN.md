<task type="auto">
  <name>Task 3: Create shared TypeScript interfaces for Profile and ChartResult</name>
  <files>web/src/types/index.ts, functions/src/types/index.ts</files>
  <action>
Create identical TypeScript interface files in both web/ and functions/ packages. These define the data contracts between frontend and backend.

**Interfaces to define:**

1. **Profile** — Birth profile record:
   ```typescript
   interface Profile {
     id: string;
     ownerDeviceId: string;
     name: string;
     birthDate: string;          // YYYY-MM-DD
     birthTime: string | null;   // HH:mm or null
     timeUnknown: boolean;
     birthPlace: string;
     lat: number;
     lng: number;
     timezone: string;           // IANA timezone (e.g., "America/Chicago")
     createdAt: string;          // ISO 8601
     updatedAt: string;          // ISO 8601
   }
   ```

2. **CreateProfilePayload** — Input for createProfile function:
   ```typescript
   interface CreateProfilePayload {
     ownerDeviceId: string;
     name: string;
     birthDate: string;
     birthTime: string | null;
     timeUnknown: boolean;
     birthPlace: string;
     lat: number;
     lng: number;
     timezone: string;
   }
   ```

3. **ChartPoint** — A celestial body's position:
   ```typescript
   interface ChartPoint {
     body: string;               // "Sun", "Moon", "Mercury", etc.
     lon: number;                // Ecliptic longitude (0-360)
     sign: string;               // "Aries", "Taurus", etc.
     degreeInSign: number;       // 0-30
     house: number | null;       // House number (1-12) or null if unknown
   }
   ```

4. **ChartHouses** — House cusp data:
   ```typescript
   interface ChartHouses {
     system: "placidus" | "whole-sign";
     cusps: number[];            // 12 cusp longitudes (0-360)
     asc: number | null;         // Ascendant longitude
     mc: number | null;          // Midheaven longitude
   }
   ```

5. **ChartAspect** — Aspect between two bodies:
   ```typescript
   interface ChartAspect {
     a: string;                  // Body name A
     b: string;                  // Body name B
     type: "conjunction" | "opposition" | "trine" | "square" | "sextile";
     orb: number;                // Actual orb in degrees
     exactness: number;          // 0-1, how exact (1 = perfect)
   }
   ```

6. **ChartMeta** — Computation metadata:
   ```typescript
   interface ChartMeta {
     houseSystem: "placidus" | "whole-sign";
     zodiac: "tropical";
     timeUsed: string | null;    // HH:mm or null
     timezoneUsed: string;
   }
   ```

7. **ChartResult** — Complete chart computation result:
   ```typescript
   interface ChartResult {
     meta: ChartMeta;
     points: ChartPoint[];
     houses: ChartHouses;
     aspects: ChartAspect[];
   }
   ```

Export all interfaces. Both files should be identical — we duplicate for MVP to avoid monorepo shared package complexity (per RESEARCH.md recommendation). Add a comment at the top: `// Shared types — keep in sync with [other path]`.

Do NOT create a shared package or workspace link — Firebase deploys functions/ in isolation and workspace links break deployment.
  </action>

- `cd functions && npx tsc --noEmit` passes
- `diff web/src/types/index.ts functions/src/types/index.ts` shows identical content (except the sync comment path)
  </verify>
