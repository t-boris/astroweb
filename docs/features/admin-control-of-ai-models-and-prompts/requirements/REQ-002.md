## Statement

The system shall let the admin choose, per AI task, a model from the server's model list (Claude, OpenAI and Gemini models) and the output limit (and temperature where the model accepts it), and shall apply a saved choice to new requests without a deploy.

## Acceptance Criteria

- [x] The model picker offers only the models in the server's list, grouped by provider, each with its label and price; models of a provider without a configured API key are shown as unavailable
- [x] Temperature is editable only when the chosen model accepts it; otherwise it is hidden and never sent
- [x] The server refuses an unknown model id, an output limit above the chosen model's limit or below a minimum, and a temperature outside 0..1, with a clear error
- [ ] After a save, new requests of that task use the new settings within 60 seconds, verified by the model id recorded with the answer where the task records one (Oracle history, compatibility readings, letters)
- [ ] For every model in the list, each task builds a request that the API accepts: parameters the model rejects are not sent, and on models whose thinking counts against the output budget the answer is not cut short by thinking
- [x] A refusal from the model is reported as a failure of that request (stars refunded where they are today), not shown as an empty answer
