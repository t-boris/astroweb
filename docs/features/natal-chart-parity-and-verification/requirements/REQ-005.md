## Statement

Verify existing and expanded natal chart calculations through reproducible full-chart comparisons against Astro-Seek under matched settings, including numerical comparisons for both dated Whole Sign birth datasets. If the original settings for a dated example cannot be independently confirmed, use its screenshot for display verification and generate a new Astro-Seek chart with the same birth inputs and explicit settings for numerical verification. Use a calculation convention for the lunar nodes, Black Moon Lilith, or Part of Fortune in numerical acceptance fixtures only when the evidence unambiguously confirms it. Agreement with a regenerated chart does not confirm the original screenshot’s point conventions. Any convention that remains ambiguous requires a separate decision under DEC-010. Cross-check the longitudes of the ten standard bodies using a separate ephemeris source independent of both Astro-Seek and AstroWeb’s calculation path, and record both sets of results as release evidence.

## Acceptance Criteria

- [ ] A repeatable full-chart comparison against Astro-Seek under matched settings covers both dated Whole Sign birth datasets and control charts covering Koch and Placidus. The third image is used for display verification because its birth inputs are unavailable.
- [ ] For each dated Whole Sign example whose original settings cannot be independently confirmed, use the original screenshot for display verification and generate a new Astro-Seek chart using the same birth inputs and explicit settings. Use that regenerated chart as the numerical reference for the dataset.
- [ ] Each Astro-Seek comparison records the birth inputs, UTC instant, coordinates, zodiac, requested and actual house systems, relevant point definitions, and aspect rules. It checks existing and added positions, angles, cusps, house assignments, retrograde status, and aspects wherever the matched reference provides them. Numerical acceptance for the lunar nodes, Black Moon Lilith, and Part of Fortune uses the confirmed point definitions recorded in REQ-002.
- [ ] For each lunar node, Black Moon Lilith, and Part of Fortune, verification unambiguously confirms the calculation convention before it is adopted in a numerical acceptance fixture. Agreement with a regenerated chart establishes agreement under its explicit settings only. If multiple definitions match the displayed precision or the available evidence cannot distinguish them, the convention remains open for a separate decision under DEC-010.
- [ ] The independent ephemeris comparison uses a source independent of both Astro-Seek and AstroWeb’s calculation path and covers the Sun, Moon, and eight planets from Mercury through Pluto. It records the source and the matched time, observing center, reference frame, and corrections used to compare longitudes.
- [ ] The verification defines tolerances and categorical comparison rules before evaluating results, reports circular angular deviations and categorical mismatches, and resolves discrepancies against those rules before acceptance.
- [ ] Release evidence includes the results of both the full-chart Astro-Seek comparison under matched settings and the independent longitude comparison, along with the inputs, settings, and results used to reproduce or regenerate the dated examples and evaluate the added point conventions. It identifies each regenerated Astro-Seek chart and records its explicit settings.
- [ ] For the same inputs, a previously cached profile chart exposes the same supported data as a fresh calculation.
