## Question

Объяснения должны быть общими или привязанными к карте пользователя?

## Why it matters

Общее определение («Марс — планета действия») — статический текст; персональное («ваш Марс в Овне в 5-м доме значит…») требует данных карты или ИИ и пересекается с вкладкой интерпретаций и платными функциями.

## Options

- **A**: Только общие определения терминов, одинаковые для всех.
- **B**: Общее определение + короткая персональная строка из существующих шаблонов интерпретаций, где они есть.

## Recommended

A — Закрывает задачу понимания UI, не задевая монетизацию интерпретаций.

## Answer

A. Только общие определения терминов, одинаковые для всех.
