## Statement

The web app shows an EN/RU consent banner that links to the privacy page (/privacy or /ru/privacy matching the current language) and initialises Firebase Analytics/GA4 only after the user grants analytics consent; the choice is persisted and can be changed later.

## Acceptance Criteria

- [ ] Before consent is granted, no request is sent to Google Analytics/Firebase Analytics endpoints.
- [ ] After the user accepts, Analytics initialises and page_view events are sent on route changes.
- [ ] After the user declines, Analytics stays uninitialised across reloads.
- [ ] The banner text is available in English and Russian via the existing i18n.
- [ ] The banner contains a working link to the privacy page in the current language.
- [ ] The user can reopen the consent choice later (e.g. from a footer or privacy-page control) and change it.
